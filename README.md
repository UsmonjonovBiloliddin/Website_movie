# 🎬 film-vibe

**film-vibe** is a modern, responsive, single-page movie platform built with **Vite + React**. It offers a smooth user experience for browsing trending movies, exploring countries, and authenticating via **Email**, **Google**, or **GitHub**. Optimized for all devices — from mobile to desktop.

🚀 **Live Demo**: [https://film-vibe.web.app/](https://film-vibe.web.app/)

---


---

## 🧩 Features

- 🔥 Trending movies via **TMDB API**
- 🌍 Country data via **REST Countries API**
- 🖼️ Random profile images via **DummyImg**
- 🔐 Authentication with **Firebase Auth** (Email, Google, GitHub)
- 💡 Clean single-page application (SPA) architecture
- 📱 Fully responsive across all devices
- ⚡ Built with **Vite** for fast development and build times

---

## 🛠️ Tech Stack

- **Frontend**: React, TailwindCSS, React Router
- **Backend/Auth**: Firebase Authentication
- **APIs**:
  - [TMDB API](https://www.themoviedb.org/documentation/api)
  - [REST Countries API](https://restcountries.com/)
  - [DummyImg](https://dummyimage.com/)
